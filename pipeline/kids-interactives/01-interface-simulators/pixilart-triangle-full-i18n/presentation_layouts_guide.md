# 🎯 Гайд по лейаутам для образовательных презентаций

## 📋 Основные типы лейаутов

### 1. 🎉 **Приветственный лейаут (Welcome Layout)**
**Когда использовать:** Начало урока, знакомство с темой
```
┌─────────────────────────────────────┐
│            🎨 ИКОНКА               │
│                                     │
│        ДОБРО ПОЖАЛОВАТЬ В           │
│         ТРЕНАЖЕР РИСОВАНИЯ          │
│                                     │
│    Краткое описание того, что       │
│    мы будем изучать в этом уроке    │
│                                     │
│         [НАЧАТЬ УРОК]               │
└─────────────────────────────────────┘
```

**Как заполнять:**
- **Заголовок:** Яркий, мотивирующий (15-25 символов)
- **Иконка:** Релевантная теме (🎨, 📚, 🔬, 💻)
- **Описание:** 1-2 предложения о пользе урока
- **CTA кнопка:** Действие ("Начать", "Приступить", "Go!")

---

### 2. 📖 **Обучающий лейаут (Instruction Layout)**
**Когда использовать:** Объяснение новых концепций, теории
```
┌─────────────────────────────────────┐
│  👨‍🏫 АВАТАР    [Шаг 2 из 7]        │
│                                     │
│         ЗАГОЛОВОК УРОКА             │
│                                     │
│  Основной текст инструкции, который │
│  объясняет что нужно делать. Текст  │
│  должен быть кратким и понятным.    │
│                                     │
│         💡 СОВЕТ ИЛИ ПОДСКАЗКА      │
│                                     │
│    [НАЗАД]              [ПОНЯТНО]   │
└─────────────────────────────────────┘
```

**Как заполнять:**
- **Прогресс:** Показать текущий шаг (Шаг X из Y)
- **Аватар:** Персонаж-учитель для эмоциональной связи
- **Заголовок:** Конкретная задача (20-40 символов)
- **Основной текст:** Четкая инструкция (50-100 слов)
- **Подсказка:** Дополнительная помощь или мотивация
- **Кнопки:** Навигация + основное действие

---

### 3. ⚡ **Интерактивный лейаут (Interactive Layout)**
**Когда использовать:** Практические задания, взаимодействие
```
┌─────────────────────────────────────┐
│ 🎯 ЗАДАНИЕ     [███████░░░] 70%     │
│                                     │
│ ┌─────────────┐ ┌─────────────────┐ │
│ │   ПАНЕЛЬ    │ │                 │ │
│ │ ИНСТРУМЕНТОВ│ │   РАБОЧАЯ       │ │
│ │             │ │   ОБЛАСТЬ       │ │
│ │ ✏️ Карандаш │ │                 │ │
│ │ 🎨 Кисть    │ │  [Интерактивная │ │
│ │ 🌈 Цвета    │ │   зона для      │ │
│ │             │ │   выполнения    │ │
│ └─────────────┘ │   задания]      │ │
│                 │                 │ │
│                 └─────────────────┘ │
│                                     │
│        💬 "Выбери цвет для           │
│           рисования треугольника"    │
└─────────────────────────────────────┘
```

**Как заполнять:**
- **Индикатор задания:** Четкое название текущей задачи
- **Прогресс-бар:** Визуальный показатель прогресса
- **Панель инструментов:** Только нужные для задачи элементы
- **Рабочая область:** Максимум пространства для практики
- **Подсказка:** Текущее действие внизу экрана

---

### 4. ✅ **Лейаут обратной связи (Feedback Layout)**
**Когда использовать:** После выполнения задания, проверка
```
┌─────────────────────────────────────┐
│              ✅ ОТЛИЧНО!            │
│                                     │
│        🎉 Задание выполнено!        │
│                                     │
│   Ты успешно нарисовал треугольник  │
│   и выбрал для него красивый цвет.  │
│                                     │
│         ⭐⭐⭐ НАГРАДА ⭐⭐⭐         │
│                                     │
│  💡 Следующий шаг: попробуем        │
│     нарисовать треугольник другого  │
│     размера                         │
│                                     │
│            [ПРОДОЛЖИТЬ]             │
└─────────────────────────────────────┘
```

**Как заполнять:**
- **Статус:** Ясный результат (✅ Отлично! ❌ Попробуй еще раз)
- **Эмоджи:** Соответствующие настроению (🎉, 😊, 🤔)
- **Описание:** Что именно пользователь сделал правильно
- **Награда:** Визуальное поощрение (звезды, бейджи)
- **Предпросмотр:** Намек на следующий шаг
- **CTA:** Мотивирующий призыв к действию

---

### 5. 🎯 **Лейаут выбора (Choice Layout)**
**Когда использовать:** Квизы, выбор инструментов, опции
```
┌─────────────────────────────────────┐
│        🤔 СДЕЛАЙ ВЫБОР              │
│                                     │
│    Каким инструментом ты хочешь     │
│         нарисовать круг?            │
│                                     │
│ ┌─────────┐ ┌─────────┐ ┌─────────┐ │
│ │   ✏️    │ │   🖌️    │ │   📐    │ │
│ │КАРАНДАШ │ │ КИСТЬ   │ │ЦИРКУЛЬ  │ │
│ │         │ │         │ │         │ │
│ │Простой  │ │Мягкие   │ │Точные   │ │
│ │инструмент│ │линии    │ │круги    │ │
│ └─────────┘ └─────────┘ └─────────┘ │
│                                     │
│          Выбери любой!              │
└─────────────────────────────────────┘
```

**Как заполнять:**
- **Вопрос:** Четкий выбор, который нужно сделать
- **Опции:** 2-4 варианта с иконками
- **Описание:** Краткие характеристики каждого варианта
- **Подсказка:** Дополнительная информация для выбора

---

### 6. 🏆 **Лейаут завершения (Completion Layout)**
**Когда использовать:** Конец урока, подведение итогов
```
┌─────────────────────────────────────┐
│           🏆 ПОЗДРАВЛЯЕМ!           │
│                                     │
│        Урок успешно завершен!       │
│                                     │
│  📊 ТВОИ ДОСТИЖЕНИЯ:                │
│  ✅ Изучил инструмент "Карандаш"    │
│  ✅ Нарисовал 5 разных фигур        │
│  ✅ Освоил палитру цветов           │
│                                     │
│  🎯 СЛЕДУЮЩИЙ УРОК:                 │
│     "Продвинутые техники рисования" │
│                                     │
│ [ГЛАВНОЕ МЕНЮ] [СЛЕДУЮЩИЙ УРОК]     │
└─────────────────────────────────────┘
```

**Как заполнять:**
- **Заголовок:** Праздничный, поздравляющий
- **Достижения:** Список того, что изучили
- **Статистика:** Конкретные цифры прогресса
- **Следующий шаг:** Мотивация к продолжению
- **Навигация:** Варианты дальнейших действий

## 🎨 Принципы дизайна лейаутов

### **Цветовая схема:**
- **Фон:** Темные тона (#1a1a1a, #2a2a2a) для меньшей усталости глаз
- **Акценты:** Яркие цвета (#00ff88, #007acc) для важных элементов
- **Текст:** Высокий контраст (#ffffff, #cccccc)
- **Ошибки:** Красные оттенки (#ff4444)
- **Успех:** Зеленые оттенки (#00ff88)

### **Типографика:**
- **Заголовки:** 18-24px, жирные
- **Основной текст:** 14-16px, обычные
- **Подсказки:** 12-14px, курсив
- **Кнопки:** 14-16px, жирные

### **Отступы и размеры:**
- **Внешние отступы:** 20-30px
- **Внутренние отступы:** 15-20px
- **Кнопки:** Минимум 44x44px для удобства нажатия
- **Иконки:** 24-48px в зависимости от важности
