# 🚀 Космодром: Атака вируса

Интерактивное веб-приложение для повторения IT-навыков: файлы, графика, документы, презентации.

## 📋 Описание

Образовательная игра для детей 7 лет, где нужно освободить космодром от вируса, выполняя задания в 4 секторах.

## 🎯 Цели обучения

- **Сектор A**: Файлы и папки (drag & drop, проводник, структура)
- **Сектор B**: Графика (Sumo Paint, заливка, инструменты)
- **Сектор C**: Документы (исправление ошибок, форматирование)
- **Сектор D**: Презентации (порядок слайдов, дизайн)

## 🌍 Локализация

Поддерживаемые языки:
- 🇷🇺 Русский (основной)
- 🇬🇧 English
- 🇪🇸 Español
- 🇮🇩 Bahasa Indonesia

## 🚀 Запуск

### На Replit
1. Импортируйте проект
2. Нажмите "Run"

### Локально
```bash
npm install
npm start
```

Откройте http://localhost:5000

## 🎮 Механика

### Состояния секторов
- 🔒 **Заблокирован** - серый, недоступен
- 🔴 **Заражён** - красное свечение, глитч
- 🟡 **В процессе** - мигание, сканирование
- 🟢 **Освобождён** - зелёное свечение

### Попытки и подсказки
- 5 попыток на каждое задание
- Подсказка появляется при 2 оставшихся попытках
- Таймера нет

### Коды для LMS
После завершения сектора ученик получает код:
- Сектор A: `FILES-2312`
- Сектор B: `GRAPHICS-2312`
- Сектор C: `DOCUMENT-2312`
- Сектор D: `PRESENT-2312`

## 🛠️ Разработка

### Добавление нового языка
1. Скопируйте `locales/ru.json` → `locales/XX.json`
2. Переведите все строки
3. Добавьте опцию в `<select id="langSelect">`

### Добавление задания
1. Создайте файл в `tasks/sector-X/task-N-name.js`
2. Используйте базовый класс задания
3. Добавьте локализацию в JSON-файлы

### Изменение стилей
- `css/main.css` - CSS переменные и общие стили
- `css/map.css` - стили карты космодрома
- `css/tasks.css` - стили интерактивных заданий
