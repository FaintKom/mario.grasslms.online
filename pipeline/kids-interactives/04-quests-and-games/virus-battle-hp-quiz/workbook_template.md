## ТВОЯ МИССИЯ

Привет, защитник сервера! 

На главный компьютер готовится напасть опасный МЕГА-ВИРУС! Чтобы его остановить, тебе нужно создать ТРИ СИСТЕМЫ ЗАЩИТЫ с помощью таблиц.

Когда все системы будут готовы, ты сможешь сразиться с вирусом в финальном тесте!

---

## СИСТЕМА 1: ЗАЩИТНАЯ СТЕНА

### ЧТО НУЖНО ЗНАТЬ:
**Таблица** - это клетки, организованные в строки и столбцы. Как шахматная доска!

### ТВОЁ ЗАДАНИЕ:
Создай защитную стену из блоков используя таблицу.

**Шаг 1:** Создай таблицу
- Вставка → Таблица → 5 столбцов, 3 строки

**Шаг 2:** Заполни таблицу текстом:

**Пример на русском:**
| | | | | |
|---|---|---|---|---|
| ЗАЩИТНАЯ СТЕНА | | | | |
| БЛОК-1 | БЛОК-2 | БЛОК-3 | БЛОК-4 | БЛОК-5 |
| ГОТОВ | ГОТОВ | ГОТОВ | ГОТОВ | ГОТОВ |

**Пример на индонезийском:**
| | | | | |
|---|---|---|---|---|
| DINDING PELINDUNG | | | | |
| BLOK-1 | BLOK-2 | BLOK-3 | BLOK-4 | BLOK-5 |
| SIAP | SIAP | SIAP | SIAP | SIAP |

**Шаг 3:** Раскрась свою стену:
- [ ] Первая строка - СЕРЫЙ цвет (как настоящая стена!)
- [ ] Вторая строка - СИНИЙ цвет (блоки защиты)
- [ ] Третья строка - ЗЕЛЁНЫЙ цвет (всё готово!)

**ПРОВЕРЬ СЕБЯ:**
- [ ] Таблица создана?
- [ ] Все цвета применены?
- [ ] Текст написан правильно?

**Первая система готова!**

## СИСТЕМА 2: ПУЛЬТ УПРАВЛЕНИЯ АНТИВИРУСОМ

### ЧТО НУЖНО ЗНАТЬ:
**Объединение ячеек** - это когда из нескольких маленьких клеток делаем одну большую. Как если бы мы убрали стенки между комнатами!

### ТВОЁ ЗАДАНИЕ:
Создай пульт с кнопками для управления антивирусом.

**Шаг 1:** Создай таблицу
- Вставка → Таблица → 4 столбца, 4 строки

**Шаг 2:** Объедини ячейки:
- Выдели все 4 ячейки первой строки
- Правая кнопка мыши → Объединить ячейки
- Напиши: **АНТИВИРУС 3000**
- Сделай то же самое с последней строкой
- Напиши: **СИСТЕМА ГОТОВА К БИТВЕ**

**Шаг 3:** Добавь кнопки управления:

**Пример на русском:**
| АНТИВИРУС 3000 (объединённая) | | | |
|---|---|---|---|
| СКАНИРОВАТЬ | ЛЕЧИТЬ | УДАЛИТЬ | ЗАЩИТА |
| СТАРТ | ПАУЗА | СТОП | ОБНОВИТЬ |
| СИСТЕМА ГОТОВА К БИТВЕ (объединённая) | | | |

**Пример на индонезийском:**
| ANTIVIRUS 3000 (объединённая) | | | |
|---|---|---|---|
| PINDAI | SEMBUHKAN | HAPUS | LINDUNGI |
| MULAI | JEDA | BERHENTI | PERBARUI |
| SISTEM SIAP BERTEMPUR (объединённая) | | | |

**Шаг 4:** Раскрась пульт:
- [ ] Заголовок (АНТИВИРУС 3000) - КРАСНЫЙ
- [ ] Кнопки действий (СКАНИРОВАТЬ, ЛЕЧИТЬ...) - ЖЁЛТЫЙ
- [ ] Кнопки управления (СТАРТ, ПАУЗА...) - ОРАНЖЕВЫЙ
- [ ] Статус (СИСТЕМА ГОТОВА) - ЗЕЛЁНЫЙ

**ПРОВЕРЬ СЕБЯ:**
- [ ] Ячейки объединены?
- [ ] Все кнопки на месте?
- [ ] Цвета применены?
- [ ] Текст по центру?

**Вторая система готова!**

## СИСТЕМА 3: ПАНЕЛЬ МОНИТОРИНГА

### ЧТО НУЖНО ЗНАТЬ:
В таблицу можно вставлять не только текст, но и картинки! Это делает информацию более понятной. Также можно изменять размеры уже готовой таблицы.

### ТВОЁ ЗАДАНИЕ:
Исправь панель мониторинга - в ней есть ошибки! Убери лишнее, вставь картинки и подними энергию до максимума!

**ГОТОВАЯ ТАБЛИЦА С ОШИБКАМИ:**

| КАРТИНКА | СИСТЕМА | СТАТУС | ЭНЕРГИЯ | ЛИШНЯЯ КОЛОНКА |
|----------|---------|--------|---------|----------------|
| [КАРТИНКА ПРОЦЕССОРА] | Процессор | Работает | ПП 40% | УДАЛИ МЕНЯ |
| [КАРТИНКА ПАМЯТИ] | Память | Работает | ППП 60% | УДАЛИ МЕНЯ |
| [КАРТИНКА АНТИВИРУСА] | Антивирус | Активен | П 20% | УДАЛИ МЕНЯ |
| [КАРТИНКА ЗАЩИТЫ] | Защита | Включена | ПППП 80% | УДАЛИ МЕНЯ |
| ЛИШНЯЯ СТРОКА | УДАЛИ | ЭТУ | СТРОКУ | ТОЖЕ |

**Шаг 1:** Удали лишнее:
- [ ] Удали последнюю колонку "ЛИШНЯЯ КОЛОНКА"
- [ ] Удали последнюю строку с текстом "ЛИШНЯЯ СТРОКА"

**Как удалить колонку:**
1. Выдели всю колонку (клик на заголовок колонки)
2. Правая кнопка мыши → Удалить столбец

**Как удалить строку:**
1. Выдели всю строку (клик на номер строки слева)
2. Правая кнопка мыши → Удалить строку

**Шаг 2:** Вставь картинки вместо текста [КАРТИНКА...]:
- [ ] Удали текст [КАРТИНКА ПРОЦЕССОРА]
- [ ] Вставь на его место картинку Процессор.png
- [ ] Повтори для всех 4 картинок
- [ ] Уменьши каждую картинку до 2 см

**Картинки уже есть внизу документа - просто скопируй и вставь их в нужные ячейки!**

**Шаг 3:** Подними энергию до 100%:
- [ ] Измени "ПП 40%" на "ПППППП 100%"
- [ ] Измени "ППП 60%" на "ПППППП 100%"
- [ ] Измени "П 20%" на "ПППППП 100%"
- [ ] Измени "ПППП 80%" на "ПППППП 100%"

**Шаг 4:** Раскрась таблицу:
- [ ] Заголовки (первая строка) - СЕРЫЙ фон
- [ ] "Работает" - ЗЕЛЁНЫЙ фон
- [ ] "Активен" - ЗЕЛЁНЫЙ фон
- [ ] "Включена" - СИНИЙ фон
- [ ] Все "ПППППП 100%" - ЖЁЛТЫЙ фон (максимальная энергия!)

**КАК ДОЛЖНА ВЫГЛЯДЕТЬ ГОТОВАЯ ТАБЛИЦА:**

**Пример на русском:**
| КАРТИНКА | СИСТЕМА | СТАТУС | ЭНЕРГИЯ |
|----------|---------|--------|---------|
| [картинка] | Процессор | Работает | ПППППП 100% |
| [картинка] | Память | Работает | ПППППП 100% |
| [картинка] | Антивирус | Активен | ПППППП 100% |
| [картинка] | Защита | Включена | ПППППП 100% |

**Пример на индонезийском:**
| GAMBAR | SISTEM | STATUS | ENERGI |
|--------|--------|--------|--------|
| [gambar] | Prosesor | Bekerja | SSSSSS 100% |
| [gambar] | Memori | Bekerja | SSSSSS 100% |
| [gambar] | Antivirus | Aktif | SSSSSS 100% |
| [gambar] | Perlindungan | Aktif | SSSSSS 100% |

**ПРОВЕРЬ СЕБЯ:**
- [ ] Удалены лишняя колонка и строка?
- [ ] Все 4 картинки вставлены и уменьшены?
- [ ] Вся энергия поднята до 100%?
- [ ] Таблица раскрашена правильными цветами?
