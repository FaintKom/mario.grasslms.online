🤖 Платформа создания уровней Robot Level Editor

🔗 Ссылка на платформу:

https://replit.com/@Mario-RafaelRa1/Python-2

0. Как запустить платформу

  1. Откройте ссылку выше
  2. Нажмите кнопку «Remix this app» (создать свою копию)
  3. Войдите через любой Google-аккаунт (или создайте аккаунт Replit)
  4. Дождитесь копирования проекта
  5. Нажмите зелёную кнопку «Run» для запуска
  6. Откройте превью сайта нажав на плюс (+) и выбрав Превью
  7. Нажмите кнопку со стрелкой (↗) в правом верхнем углу окна с сайтом, чтобы открыть его во внешнем окне
💡 ВАЖНО: Скопируйте ссылку из внешнего окна — именно её нужно давать ученикам. Ссылка будет вида: ваш-проект.replit.app

1. Создание комнаты для урока

Чтобы начать работу с учениками:

  1. Откройте сайт платформы в браузере
  2. В блоке «Buat Ruangan» введите название урока (например: «Робототехника — 5А»)
  3. Нажмите кнопку «Buat Ruangan»
  4. Запомните или запишите 4-значный код комнаты (отображается вверху страницы)

2. Как поделиться кодом с учениками

Есть несколько способов:

Способ Описание
Отправить ссылку Скопируйте URL из адресной строки браузера
Отправить в чат Продиктуйте или напишите в чат 4 цифры кода
Показать на экране Откройте комнату через демонстрацию экрана

Пример:

  • Код комнаты: 4521
  • Ссылка: сайт.replit.app/room/4521

3. Управление комнатой (режим учителя)

Вы можете удалять уровни учеников:

  1. Находясь в комнате, нажмите на кнопку 🔐 Mode Guru
  2. Введите секретный код: 10122025
  3. Появится кнопка «🚪 Keluar» — это означает, что режим активен
  4. Теперь вы можете удалять уровни (кнопка 🗑️ рядом с каждым уровнем)
  5. Нажмите «Keluar» для отключения режима учителя
⚠️ Важно: Режим учителя работает только в текущей комнате. При переходе в другую комнату права сбрасываются.

4. Что делают ученики

Инструкция для учеников (можете продиктовать):

  1. Откройте сайт по ссылке от преподавателя
  2. Введите код комнаты и нажмите «Masuk»
  3. Нажмите «✨ Buat Level»
  4. Введите своё имя и выберите размер сетки (5×5, 8×8 или 10×10)
  5. Нажмите «Mulai Membuat»
  6. Разместите на сетке элементы (см. ниже)
  7. Нажмите «🎮 Uji Level» и пройдите свой уровень
  8. После прохождения нажмите «📤 Publikasi»
  9. Готово! Можно играть в уровни одноклассников

Элементы для размещения:

  • 🤖 Робот — откуда начинает
  • 🏁 Финиш — куда нужно дойти
  • 💎 Кристаллы — нужно собрать
  • 🪨 Камни — препятствия

5. Полезные функции

🖼️ Предпросмотр уровней
Каждый уровень показывает миниатюру с расположением объектов прямо в списке.

❤️ Система лайков
Ученики могут ставить лайки понравившимся уровням. Нажмите кнопку «❤️ Suka» во время игры. Уровни с большим количеством лайков отображаются выше.

🏷️ Названия уровней
Каждый уровень получает уникальное имя: Имя-123 (имя автора + случайный код).

✅ Проверка перед публикацией
Уровень можно опубликовать только после того, как автор сам его прошёл. Это гарантирует, что все уровни проходимы.

6. Секретные коды

Код Роль Возможности
10122025 Учитель Управление только текущей комнатой
10122025Ad Администратор Полный доступ ко всем комнатам (вводится как код комнаты на главной странице)
