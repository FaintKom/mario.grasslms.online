Как запустить платформу

Откройте ссылку на платформу (см. выше)
Нажмите кнопку «Remix this app» (создать свою копию)
Войдите через любой Google-аккаунт (или создайте аккаунт Replit)
Дождитесь копирования проекта
Нажмите зелёную кнопку «Run» для запуска
Откройте превью сайта, нажав на плюс (+) и выбрав Превью
Нажмите кнопку со стрелкой (↗) в правом верхнем углу окна с сайтом, чтобы открыть его во внешнем окне
💡
ВАЖНО: Скопируйте ссылку из внешнего окна — именно её нужно давать ученикам. Ссылка будет вида: ваш-проект.replit.app

Создание комнаты для урока

Чтобы начать работу с учениками:

Откройте сайт платформы в браузере
В блоке «Buat Ruangan» введите название урока (например: «Робототехника — 5А»)
Нажмите кнопку «Buat Ruangan»
Запомните или запишите 4-значный код комнаты (отображается вверху страницы)
2

Как поделиться кодом с учениками

Есть несколько способов:

Способ Описание
Отправить ссылку Скопируйте URL из адресной строки браузера
Отправить в чат Продиктуйте или напишите в чат 4 цифры кода
Показать на экране Откройте комнату через демонстрацию экрана

Пример:

Код комнаты: 4521
Ссылка: сайт.replit.app/room/4521
3

Управление комнатой (режим учителя)

Вы можете удалять уровни учеников:

Находясь в комнате, нажмите на кнопку 🔐 Mode Guru
Введите секретный код: 10122025
Появится кнопка «🚪 Keluar» — это означает, что режим активен
Теперь вы можете удалять уровни (кнопка 🗑️ рядом с каждым уровнем)
Нажмите «Keluar» для отключения режима учителя
⚠️
Важно: Режим учителя работает только в текущей комнате. При переходе в другую комнату права сбрасываются.

Что делают ученики

Инструкция для учеников (можете продиктовать):

Откройте сайт по ссылке от преподавателя
Введите код комнаты и нажмите «Masuk»
Нажмите «✨ Buat Level»
Введите своё имя и выберите размер сетки (5×5, 8×8 или 10×10)
Нажмите «Mulai Membuat»
Разместите на сетке элементы (см. ниже)
Нажмите «🎮 Uji Level» и пройдите свой уровень
После прохождения нажмите «📤 Publikasi»
Готово! Можно играть в уровни одноклассников

Полезные функции

🖼️ Предпросмотр уровней
Каждый уровень показывает миниатюру с расположением объектов прямо в списке.
❤️ Система лайков
Ученики могут ставить лайки понравившимся уровням. Уровни с большим количеством лайков отображаются выше.
🏷️ Названия уровней
Каждый уровень получает уникальное имя: Имя-123 (имя автора + случайный код).
✅ Проверка перед публикацией
Уровень можно опубликовать только после того, как автор сам его прошёл. Это гарантирует, что все уровни проходимы.
