A web page has three layers

Every web page you have opened is built from three layers, with HTML as the bones, CSS as the clothes and JavaScript as the movement. On this page you can switch each layer off and see what it was doing.

This card has a switch for each layer. With CSS off the styling disappears, and with JavaScript off the button stops answering.
