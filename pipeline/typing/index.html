What this is

A scenario that runs inside an interface you have used every working day for a decade. No tutorial, no onboarding, no new vocabulary — the shell explains how to play, so the writing is free to do everything else.

Four decisions, each launched from a different height. The game never says a choice was wrong. Afterwards it shows you the sentence that was on your screen, beside the sentence you replaced it with.

The framework, and whose it is

The rungs are the Ladder of Inference — observable data, selected data, meaning, assumption, conclusion, action. It belongs to Chris Argyris, developed at Harvard and carried into wider use by Peter Senge.

I did not invent it. I made it playable, which is a different job and the only one I am claiming here.

How the feedback behaves

  • Arrives mid-play, never as a report at the end
  • About how you decided, never about who you are
  • Reframes instead of evaluating
  • Stays tentative — you should need it less next time
  • No scores, no percentage, no stars
  • Every note ends with one thing to try tomorrow

How it was made

One HTML file. No framework, no build step, no dependencies — it will still open in ten years. Claude did most of the typing and I did the arguing, over about a day.

The longest part was the dwell on the typing indicator, which is the only reason any of it feels like a room.
