The test forms

A Flask backend and a set of Tampermonkey scripts fill matching, categorisation and fill-in-the-blank tests on the teacher-training platforms. Each instructional designer gets back about five hours a week that used to go into clicking.

highlights
  • Flask + Tampermonkey
  • Matching · categorisation · fill-in
  • ~5h / wk saved per ID

The bot pushes homework prompts into Telegram, collects what comes back and lays it out for instructors in a triage view. Learners stay in the app they already have open.
